# Contributing to GreenQuest

This is a collaborative university project. Coordinate implementation with the team and track planned work in Jira.

## Develop

1. `git clone https://github.com/Sayeed843/GQuest.git`
2. `cd GQuest && npm install`
3. `npx expo install --fix`
4. `npm start` and scan in a compatible Expo Go app.
5. Before opening a pull request, run `npm run typecheck` and `npx expo-doctor@latest`.

## Branches and pull requests

- Keep `main` demo-ready.
- Make changes on branches such as `feature/dashboard` or `fix/quest-progress`.
- Explain what you changed, how it was tested, and which Jira task it supports.
- Prefer focused pull requests and review each other's code.
- Avoid committing private test data, secrets, mobile build artifacts and `node_modules/`.

## Project integrity

- Carbon and sustainability metrics require a verified methodology, units, references and assumptions before publication.
- Mark illustrative data clearly.
- Discuss the choice of open-source license with all team members before adding one.
