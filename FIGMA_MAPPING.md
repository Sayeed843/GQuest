# GreenQuest NOVA — Figma screen mapping

Source: [GreenQuest NOVA · Eight UI Screens](https://www.figma.com/design/bfsT5gInmbXH07rarX9nSr)

The eight frames below are the source of the UI concept. The React Native implementation lives in [App.tsx](App.tsx).

| Screen | Figma node | UI behavior in prototype |
|---|---|---|
| Welcome & Onboarding | `2:2` | Enter the app without registration |
| Home Dashboard | `2:5` | Show overview, XP, current quest and suggestions |
| Lifestyle Assessment | `2:8` | Choose answers in a four-question flow |
| Carbon Footprint Insight | `2:11` | Display illustrative example breakdown |
| Smart Challenge Recommendations | `3:2` | Present a rule-based best match and alternatives |
| Green Challenges | `3:5` | Search and filter available challenges |
| Challenge Details | `3:8` | Read steps, challenge description and join |
| Challenge Progress — Completed | `3:11` | Log actions, celebrate completion and earn XP |

## Visual direction

Original NOVA palette includes dark navy (`#12142E`), purple (`#775BFA`), deep violet (`#5B42DD`), coral pink (`#FE7B94`), yellow (`#FFD05B`) and pale lilac (`#EEE9FF`).

Designs are a responsive **interpretation**, not exported screenshots or pixel-perfect reproductions; some decorative Figma assets were not ported exactly.

## Scope

Carbon figures are illustrative placeholders, and challenge recommendations are rule-based. Neither scientific validation nor machine learning is part of this first prototype.
